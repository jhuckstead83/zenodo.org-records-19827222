# Artifact Map

This repository is a reproducibility front door for the Zenodo record:

- Zenodo: https://zenodo.org/records/19827222
- Repository: https://github.com/jhuckstead83/zenodo.org-records-19827222

## Main evidence stack

### 1. Broad-board resolution ablation
Supports the claim that the dominant organizing coordinate remains `h1` across 130k, 90k, 70k, and 52k boards.

### 2. Terminal-band ladder
Compares the final 28.5B to 31.5B band at 52k, 8k, and 1k resolution.

### 3. Terminal 8k matched-packet null
Tests whether the observed concentration can be explained by packet morphology alone.

### 4. Terminal 8k jackknife robustness
Tests whether the phase lock is driven by a small outlier subset of packets.

## Interpretation scope

These artifacts support an observed-horizon empirical claim. They do not assert a closed asymptotic law beyond the observed horizon.
